# wp12 — CI 현대화

## 실측 문제

| 파일 | 문제 | 수정 |
|---|---|---|
| `ci.yml` | `engines: node>=18` 선언과 매트릭스 하한 20 불일치 | 매트릭스에 18 추가하거나 engines 상향. **engines 를 >=20 으로 올리는 쪽**이 맞다 — Node 18은 2025-04 EOL |
| `ci.yml` | 사이트 빌드 없음 | `npm --prefix site ci && npm --prefix site run build` 잡 추가 |
| `pages.yml:26` | `npm install` (잠금파일 무시) | `npm ci` |
| `publish.yml:14` | `npm install` | `npm ci` |
| `publish.yml` | `permissions` 없음 | `contents: read` + `id-token: write` 명시 |
| `publish.yml:16` | provenance 없음 | `npm publish --provenance --access public` |

## engines 상향 근거

Node 18은 2025-04-30 EOL. 현재 CI 매트릭스가 20/22/24이고 18을 실제로 검증하지 않는다.
`package.json`의 `engines`를 `>=20`으로 올려 **선언과 검증을 일치**시킨다.
이건 사용자 대면 계약 변경이므로 README/docs 뱃지도 함께 본다.

## 하지 않는 것

새 CI 서비스 도입, 액션 대량 교체(`@v4`는 현행), 배포 정책 변경, 캐시 전략 변경.

## 검증

- 워크플로 YAML 문법 유효성 (파싱)
- `npm ci`가 로컬에서 성공하는지 (잠금파일 정합성)
- engines 상향 후 `npm run build`, 테스트 통과
