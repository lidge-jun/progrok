# progrok

Run `progrok skill` for the full API surface, usage patterns, models, and tools.
Run `progrok skill --json` for machine-readable skill output.
Run `progrok skill path` for the resolved skill file path.
Run `progrok capabilities --json` for dynamic metadata (models, endpoints, tools, ports).

Before changing source, read `structure/INDEX.md` — layer responsibilities, import
direction, and the contracts that must not break.
